# Лендинг интенсива по Seedance 2.5 (школа CreAIte) — дизайн

## Назначение

Одностраничный лендинг для набора на 7-дневный интенсив по AI-генерации видео
в Seedance 2.5. Цель страницы — убедить целевую аудиторию (видеографы,
моушн-дизайнеры, маркетологи, начинающие AI-видео-специалисты) записаться на
курс. Сайт должен выглядеть эффектно и создавать ощущение «крутости» и
реального профессионального результата (курс строится вокруг настоящего
проекта для ОККО).

## Контент курса (факты)

- **Название**: Интенсив по Seedance 2.5 от школы CreAIte
- **Спикер**: Эрадж Нидоев (основатель школы CreAIte)
- **Формат**: работа над реальным проектом для ОККО
- **Длительность**: 7 дней
- **Старт**: 17 сентября 2026 (точное время не зафиксировано — на сайте
  используется 10:00 МСК как значение по умолчанию для таймера; заменить при
  необходимости в `js/main.js`, константа `START_DATE`)
- **Цена**: 28 000 ₽, доступна рассрочка
- **Программа**:
  - День 1 — пайплайн, возможности нейросети, экономика проекта; старт
    работы над проектом: распределение по командам, разбор сценария/брифа,
    подбор референсов
  - День 2 — создание персонажа и мира, генерация персонажа в образе,
    локации, подходы к формату; промпт для text-to-video; практика:
    кадры в формате text-to-video
  - День 3 — разбор ошибок text-to-video; формат photo-to-video и работа с
    ключевыми кадрами; практика: видеокадры по ключевым кадрам
  - День 4 — формат video-to-video, редактура видео, motion control;
    практика: генерация и отбор видеокадров
  - День 5 — пост-продакшн: звук (музыка и озвучка), монтаж и темпо-ритм;
    практика: монтаж, разбор неработающих кадров и их замена
  - День 6 — финальная обратная связь от Эраджа, доработка роликов
  - День 7 — обратная связь от экспертов

## Технический стек

Статический сайт без сборки: `index.html` + `css/style.css` + `js/*.js`,
открывается напрямую в браузере или заливается на любой хостинг.

Внешние зависимости через CDN (без npm/бандлера):
- **GSAP + ScrollTrigger** — скролл-анимации
- Собственный **vanilla WebGL** фрагментный шейдер для фонового эффекта
  (без Three.js — легче и не требует зависимости ради простого фона)

## Визуальный стиль

- **Фон**: чёрный (`#000` / `#111`)
- **Акцент**: кислотно-лаймовый `#D7FF28` (переменная `--acid`) — единственный
  яркий цвет; используется в заголовках-акцентах, рамках карточек,
  чекбоксах, подчёркиваниях
- **Шрифты**:
  - `Unbounded` (700/800) — заголовки h1/h2/h3, геометричный display-шрифт
  - `Golos Text` — основной текст (body-l/body-m)
  - `Caveat` — рукописные «меловые» акценты-заметки (chalk-note)
  - моноширинный (`--font-mono`) — служебные метки по углам блоков
    (`meta tl/tr/bl/br`)
  - Шрифты подключаются через Google Fonts (единственный разрешённый внешний
    хост помимо GSAP CDN)
- **Меловая графика**: SVG-«доодлы» (подчёркивания, стрелки, линии) с
  SVG-фильтром `chalkRough` (`feTurbulence` + `feDisplacementMap`) — даёт
  неровный рукописный вид, имитацию мела на доске
- **Карточки (`.card`)**: тонкая белая рамка `rgba(255,255,255,.28)`,
  полупрозрачный фон; акцентные карточки — рамка/фон в лайме
  `rgba(215,255,40,...)`
- **WebGL-фон**: монохромный анимированный шум/частицы в чёрно-белых тонах
  (имитация меловой пыли в воздухе) с редкими вспышками лаймового —
  используется в hero и в финальном CTA-блоке; приглушённый, не спорит с
  видео и меловой графикой
- **Доступность**: `prefers-reduced-motion` отключает WebGL-шейдер и тяжёлые
  GSAP-анимации, оставляя статичный фон и мгновенное появление контента

## Структура страницы (секции по порядку)

1. **Шапка** — липкая, лого CreAIte, якорные ссылки (Программа / Галерея /
   Спикер / Цены / Отзывы / FAQ), кнопка «Записаться»; сжимается при скролле
2. **Hero** — на весь экран: `<video>` с реальным клипом Seedance (плейсхолдер
   до получения файлов) + монохромный WebGL-шум как амбиентный фон;
   заголовок про создание кино с ИИ за 7 дней, подзаголовок с упоминанием
   проекта для ОККО, кнопка CTA, индикатор скролла
3. **Плашка доверия** — акцентный блок «Реальный проект для ОККО»
4. **Программа** — вертикальный таймлайн 7 дней, каждый день — раскрывающаяся
   карточка с содержанием по программе; появление карточек через
   ScrollTrigger с stagger
5. **Галерея** — сетка видео-превью (плейсхолдеры), автопроигрывание при
   наведении/появлении в вьюпорте, лайтбокс по клику
6. **Спикер** — Эрадж Нидоев: фото (заглушка), био, опыт, бренд школы CreAIte
7. **Цены** — карточка тарифа 28 000 ₽ + пометка о рассрочке, список того,
   что входит, кнопка CTA (плейсхолдер-ссылка)
8. **Отзывы** — 3 карточки-заглушки (quote/имя/роль) с пометкой на замену
9. **FAQ** — аккордеон
10. **Финальный блок** — таймер обратного отсчёта до 17 сентября 2026,
    повторная кнопка CTA
11. **Футер** — бренд CreAIte, соцсети/контакты (заглушки), копирайт

## Анимации и интерактив (GSAP + ScrollTrigger)

- Fade/slide-up reveal при скролле для всех секций
- Stagger-появление карточек программы и галереи
- Счётчики чисел (например, «28 000 ₽», «7 дней») анимируются при появлении
  в вьюпорте
- Заголовок в hero «прилипает» поверх видео при первом скролле
- Аккордеоны программы и FAQ — плавное раскрытие/закрытие
- Лайтбокс галереи — fade + scale появление

## Тестирование (ручной чек-лист, т.к. проект статический)

- Проверка вёрстки на брейкпоинтах: мобильный (~375px), планшет (~768px),
  десктоп (~1440px)
- Lighthouse: производительность и доступность
- Проверка работы таймера обратного отсчёта (корректный расчёт до
  17.09.2026)
- Проверка поведения при `prefers-reduced-motion: reduce`
- Проверка поведения `<video>` при отсутствии файла (должен показываться
  `poster`, без сломанной вёрстки)
- Проверка автопроигрывания видео на мобильных (muted + playsinline)
